# v1.2.17v — Appearance Studio Control Fixes

Focused reliability pass for Appearance Studio.

- Element Visibility now has a dedicated bottom horizontal scroll rail and a wider device matrix.
- Confidence Width is contained inside the matchup card instead of pushing the confidence area off-card.
- Global Image X/Y now acts as the base position for both teams; Home/Away controls are relative adjustments, so the main sliders visibly work.
- Correct and Incorrect result overlays support Solid or Gradient mode, two colors, independent opacity per color, and gradient angle.
- Image-question text overlay gradients support independent Color 1 and Color 2 opacity.
- Overlay controls are opened and clearly labeled in the Studio.
