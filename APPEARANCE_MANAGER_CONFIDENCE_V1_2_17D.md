# v1.2.17d — Appearance Manager + Confidence Integration

Final checkpoint of the v1.2.17 plan.

## Added
- Admin → Appearance Manager route.
- Automatic one-time Appearance sheet setup on first manager load.
- Create and edit reusable Image Packs.
- Upload pack images through the existing Awards App Drive image storage.
- Per-game image overrides with upload support.
- Create/edit Theme Packs with semantic density, typography, team treatment, corners, spacing and colors.
- Live theme preview in the manager.
- Assign an Image Pack and Theme Pack to any game without rebuilding the game.
- Confidence player cards now resolve images in this order: game override → assigned Image Pack → existing sports/game image.
- Confidence player cards now consume assigned Theme Pack tokens for density, name/city sizing, unselected treatment, corners, spacing, accent, surface, text, live, correct and incorrect colors.

## Scope remains locked
This checkpoint does not alter Confidence pick/save/scoring rules, Ranking, Survivor logic, Awards result logic, or Reality TV workflows.
