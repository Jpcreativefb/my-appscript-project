# v1.2.18c3 — Hub Appearance Live Preview + Save Feedback

- Adds a large live Hub/Navigation preview that reacts immediately to solid/gradient color changes.
- Shows image/icon previews immediately for URL, file upload, and camera choices.
- Shows explicit per-asset states: preview only, uploading/importing, saved to Google Drive, external URL saved, or failed.
- Shows an overall Saved / Unsaved changes / Saving / Failed badge.
- Avoids repainting the entire Appearance page during image upload/import so the chosen preview stays visible.
- Save Changes gives inline Saving -> Saved feedback.
