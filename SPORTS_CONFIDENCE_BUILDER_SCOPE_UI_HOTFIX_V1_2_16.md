# Sports Confidence Builder Scope UI Hotfix v1.2.16

## Purpose
Make the Sports Builders Load By control unambiguous.

## Fix
- Date Range fields are now truly hidden when Load By = League Week.
- Season/Phase/Week fields are hidden when Load By = Date Range.
- Builder help/status text now states that only the selected mode fields are required.
- No Sports Engine, scoring, wager, or Confidence settlement behavior changed.

## Deployment
Frontend-only change. Push to GitHub/Cloudflare. No Apps Script version or deployment is required for this UI hotfix.
