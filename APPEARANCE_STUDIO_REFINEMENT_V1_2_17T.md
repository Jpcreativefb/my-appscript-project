# v1.2.17t — Appearance Studio Refinement

This frontend-only refinement closes the remaining Appearance Studio usability/runtime gaps before moving on from the designer work.

## Included
- Element Visibility matrix can horizontally scroll so Mobile checkboxes are reachable.
- Page, Header, Sort/Toolbar, Save button, Question Card, Question Header, Answer, and Selected Answer support solid/gradient backgrounds.
- Image question controls now include zoom, X/Y position, opacity, overlay type/color/placement/angle.
- Team Text Readability Overlay sits between team artwork and City/Team text.
- Winner Overlay / Decoration supports solid/gradient overlays plus trophy, crown, medal, star, or check decorations and placement.
- Preview final win/loss states now drive normal question cards as well as matchup cards.
- Confidence Width is no longer hard-capped by the old mobile grid rules.
- Save and Apply to Game buttons show Saving/Saved and Applying/Applied feedback.
- Quick presets: Basic, Simple, Advanced, Mobile Friendly.
- Live Picks page now applies the complete pagePresentation class list from the shared theme runtime.
- Initial Picks render uses a styled loading shell while appearance resolves instead of flashing the base game first.

No pick/scoring/schedule logic is changed.
