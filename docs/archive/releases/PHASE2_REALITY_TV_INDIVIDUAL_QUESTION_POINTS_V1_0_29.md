# Phase 2 Reality TV Individual Question Points v1.0.29

Adds per-question point controls to the Reality TV Show Format & Question Template Manager.

- Separate elimination/exit points per season.
- Editable points beside every preset and custom question.
- Current open questions update when the pack is saved.
- Final historical questions retain their original points.
- Future episodes/legs/rounds inherit the saved template points.
- Applied points are stored on RealityEpisodeQuestions for audit/display.
