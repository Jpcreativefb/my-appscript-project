# Sports Advanced Stats Engine v1.1

- Added `SportsTeamGameStats`.
- Added `SportsStatCheckpoints`.
- Added MLB and NFL team-stat normalization.
- Added derived MLB runs and NFL points/touchdowns.
- Added end-of-inning, quarter, halftime, and first-half two-minute checkpoint capture.
- Added checkpoint precision (`EXACT_BOUNDARY` / `POLL_SNAPSHOT`).
- Added public read-only team/checkpoint APIs.
- Added protected advanced-stat setup/refresh/status APIs.
- Added advanced-stat status to the Sports Admin dashboard.
- Integrated checkpoint capture into live score polling.
