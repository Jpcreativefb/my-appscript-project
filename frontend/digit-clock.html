Google Sheets bulk entry

Use the dedicated import tabs in the PATTC Google workbook. Games use LeagueID, SeasonID, Week, Sport, ESPNEventID and optional Group. Numbers use those identifiers plus Digit, PlayerName and optional Username. Leave Week, Sport or ESPNEventID blank in a number row to match all games in this season.

The app reads these tabs directly; you do not need to download or upload a file. Save league changes before previewing an import.
