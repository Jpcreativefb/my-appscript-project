# v1.2.17m — Appearance Studio Canvas + Layers

This checkpoint improves the visual designer without changing Confidence gameplay.

## Included
- Fixed-width Desktop (1180px), Tablet (820px), and Mobile (390px) preview canvases.
- Full Preview / Show Controls toggle so the design can use the full browser width.
- Smaller control rail with no nested scrollbar; most control groups start collapsed.
- Compact Theme Actions bar moved below the designer.
- Image Layer control: inline image or true bottom/background layer with text and scores above it.
- Full-panel image artwork reaches the team button edges independently of text padding.
- Team Order control: Away-left/Home-right or Home-left/Away-right.
- Optional independent Home/Away text alignment, score position, and image horizontal focal point.
- Runtime Confidence card consumes the same Home/Away and image-layer settings as the Studio preview.

## Not changed
- Picks, confidence scoring, locks, schedules, odds, Image Pack storage, and live-score logic.
