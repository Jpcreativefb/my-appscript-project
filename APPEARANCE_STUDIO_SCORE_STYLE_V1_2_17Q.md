# v1.2.17q — Appearance Studio Score Styling

Adds independent score-badge styling to Appearance Studio without changing the scoreboard/status strip.

## Controls
- Score background color
- Score background opacity
- Score font color
- Score border color
- Score border opacity
- Horizontal and vertical padding
- Corner radius

Score font size remains in Typography. Correct and incorrect final-result score colors remain separately controlled by the existing Result Typography settings.

This release is frontend-only.
